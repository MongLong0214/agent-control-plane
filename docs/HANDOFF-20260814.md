## 3. Verification protocol — do not skip this

Twelve lanes were returned during this closeout, almost always because **the code was right and its named
regression test passed with the enforcement deleted**. Several rounds surfaced defects worse than the
ticket being fixed. The protocol that caught them:

1. **Blind review by grok** — `scratchpad/grok-blind.sh`. Blind means the reviewer gets the diff and the
   original issue body only: no `HANDOFF-REPORT.md`, no work packet, no issue comments. This matters — the
   same code reviewed non-blind returned MERGE twice where blind found BLOCKERs.
2. **Independently reproduce the verdict by mutation** before merging. Delete the enforcement, watch the
   named test fail, restore it.

That second step caught a trap worth remembering: mutating `relativePath()` in the guard changes nothing —
53 tests still pass. The real containment enforcement is `worktreePathOverlap()`, and only mutating *that*
proves it. **A reviewer naming a function is not evidence that it is the enforcement.**

Delegation: **terra** for judgement work, **luna** for fully-specified mechanical work, **sonnet** if a
Claude subagent is needed. **`gpt-5.6-sol` is barred** (owner directive) — its launchers are sealed as
`DISABLED-*`. Cap concurrent codex lanes at 3; a lane dying inside 60s is a spawn failure, not a result —
retry once after backoff (`scratchpad/lane.sh` implements this).
